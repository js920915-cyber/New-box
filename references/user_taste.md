# 대표 카드뉴스 취향 노트 (매 주제 시작 전에 읽고, 피드백마다 갱신)

→ 주제마다 대표 피드백을 여기에 쌓고, 다음 카드뉴스 기획·대본·디자인에 먼저 적용한다. 근거·안전 규칙(AGENTS.md)보다 앞서지 않는다.

## 흐름·구성
- **질문형 표지**를 좋아한다. 독자가 실제로 묻는 말투 그대로. 예: "접지, 짧을수록 좋을까?", "착지를 다르게 하니까 부상을 덜 당해?"
- 연구 하나를 **이야기처럼** 따라가는 해설형: 누가 → 어떻게 → 결과 → 그런데(반전) → 왜 → 그래서 나는?
- 마지막 2장은 **바로 행동할 수 있게**: "그럼 무슨 보강 운동?", "바꾸기 전 체크리스트". 추상적인 원칙(①목적 ②운동량…)보다 **직관적인 행동**을 원한다.
- 연구 참가자 조건(누가 참가했는지)을 꼭 넣어 오해를 막는다.

## 말투·용어
- 짧고 쉬운 말. "실험" 대신 "연구·진행" 같은 일반 용어.
- 전문용어는 **빼지 말고 넣되 바로 풀어 준다** (예: "수직 평균 부하율(VALR) — 발이 닿은 직후 힘이 얼마나 빠르게 커지는지").
- 어려운 숫자·단위(예: 70 BW/s)는 카드에서 빼고 캡션으로. "기울기가 큰 사람"처럼 그림으로 이해되는 말을 쓴다.
- 단정보다 **제안 톤**. 근거가 정답이 아닐 수 있다고 본다.

## 시각
- **그래프를 좋아한다.** 결과 수치는 막대그래프, 개념은 대표가 준 그래프 형태를 다시 그려 넣는다(그래프 안 작은 설명 글씨 OK). 개념 그래프에는 '예시' 표기.
- 사진은 **억지로 연출한 AI 사진을 싫어한다.** 밈 느낌의 자연스러운 스냅(폰카메라·표정 위주)을 좋아한다. 실제 밈 원본은 저작권 때문에 쓰지 않고 **밈 형식**(전/후 2컷, ✕/○ 2단 등)만 빌린다.
- 근거 카드에 **참고문헌을 카드 안에 작게 표기**해 달라고 한다.
