# 이번 대화의 최종 디자인 기준 — ACL V3

2026-10-12 최종 결과를 독립 복사해 보존했다. 이후 작업에서 제작 폴더를 수정해도 이 형태 기준은 유지한다. 최신 사용자 지시가 우선이다.

최신 사용자 수정까지 반영한 스냅샷: 글씨를 한 단계 굵게/크게, 핵심 문구 크기 대비 확대, 5장 파란 세로선 제거, 5장 좌우 제목 top 차이 0px. 영상 카드 형식은 [5종 라이브러리](../../templates/video_cards/README.md)를 교대 사용하며 이 4장은 T01의 예시다.

| 파일 | 참고할 형태 |
|---|---|
| [01.png](./01.png) | 역동적으로 달리는 사람, 굵은 제목·블루 키워드·짧은 공감 후킹, 하단 제작/출처 표시 없음 |
| [02.png](./02.png) | 하나의 수치와 오해 교정, 기간만으로 판단하지 않는 설명 |
| [03.png](./03.png) | 긴 계산식 대신 LSI와 짧은 설명, 필요한 평가 항목 |
| [04.png](./04.png) | 카드 내부의 큰 영상 창, 주변 질문형 타이포, 높이/기울임 대비, 곡선 화살표 |
| [05.png](./05.png) | 트레이너 중심의 계획과 단계별 진행, 집도의 역할 구분 |

| [04-video-background.png](./04-video-background.png) | 삽입 안내 문구 없는 편집 배경 |
| [04-video-overlay.png](./04-video-overlay.png) | 864×486 창을 투명하게 뚫은 PNG 오버레이 |

전체 1080×1350. 영상 창 x=108,y=440,864×486(16:9). 이 수치는 가로 영상형의 출발점이며 다른 촬영/주제에 맞춰 조정한다. source 구현은 [build.py](../../content/acl-return-to-running/source/build.py), [render.cjs](../../content/acl-return-to-running/source/render.cjs), 사용 안내는 [video-template/README.md](../../content/acl-return-to-running/video-template/README.md).

**모양을 참고하고 임상 수치/문구/동작을 자동 재사용하지 않는다.** 4장은 사용자 영상 미제공 상태의 삽입 템플릿이며 영상 자체를 검수한 자료가 아니다. 카드/배경/오버레이 총 8개이며 원래 references의 17개 이미지는 그대로 유지한다.
