# 승인된 기본 외곽 디자인 — C01

**이전 선택 기록:** 같은 날짜의 후속 사용자 지시로 현재 기본값은 [B01 얇은 라운드 프레임](../approved_frame_b01/README.md)으로 변경되었다. 아래 내용은 과거 승인 이력이며 최신 제작에는 B01을 적용한다.

2026-10-12 사용자 선택: 발전 시안 **1번 블루 그라데이션**.

[01.png](./01.png)는 승인된 실제 시안의 독립 복사본이다. 글의 가운데 정렬·기존 카드 내용은 비교 맥락이며, 이후 주제의 임상 문구는 새로 작성/검증한다.

형태 기준: 연한 블루 그라데이션 띠 + 얇은 이중 윤곽 + 작은 상하 포인트. 새 카드의 기본 외곽 디자인으로 적용한다.

재사용: [SVG](../../templates/card_frames/C01.svg), [정확한 수치/레이어 안내](../../templates/card_frames/README.md).

우선순위: 최신 사용자 지시 > 이 승인된 외곽 프레임/가운데 정렬 > approved_acl_v3의 카드 구성 > user_selected > original. 서로 다른 기준이므로 외곽 프레임 선택을 이유로 타이포/임상/영상 지침을 버리지 않는다.
