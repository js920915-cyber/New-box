`article.card`는 position:relative인 고정 아트보드. SVG를 첫 자식으로 삽입하고 `position:absolute; inset:0; width:1080px; height:1350px; pointer-events:none`으로 배치한다. 제목/사진/영상 레이어는 기존의 위치를 유지한다. 프레임 적용을 위해 모든 자식의 position을 일괄 relative로 바꾸면 절대좌표 영상 배치가 깨지므로 그렇게 하지 않는다.

독립 SVG 레이어를 편집 소스에 보존한다. 표지·본문·영상 카드 모두 동일한 프레임을 사용한다. 영상 오버레이는 프레임을 포함한 카드에서 영상 창만 투명하게 뚫는다. 문구 없는 흰 바탕이 필요하면 기존 blank-background를 그대로 사용하고 프레임은 오버레이에 둔다.

고정 값으로 재사용하고, 반복 제작을 이유로 선 두께·색 농도·장식 수를 늘리지 않는다. 본문 왼쪽 파란 세로 장식선 금지와는 별개의 승인된 **외곽 프레임**이다. 로고/페이지 번호/하단 출처를 추가하지 않는다.
