# 영상 카드 5종 검수

- T01 가로+질문, T02 세로+옆 설명, T03 좌우 비교, T04 큰 질문, T05 동작 순서: 구조가 서로 다름.
- 미리보기/배경/오버레이 각 5개, 총 15개 실제 PNG. 모두 1080×1350.
- 5종 원본과 360×450 미리보기를 실제 열어 확인. 편집용 깨끗한 배경 5개도 확인.
- 제목 기본 마진으로 생긴 초기 T03 제목/리드 겹침을 발견해 h1 margin=0으로 수정 후 재렌더/시각 검수.
- DOM 안전 영역/가로 넘침/콘텐츠 영역 간 겹침 검사 PASS. T03 좌우 제목 top=344px, 차이0px. 기록: qa/layout-check.json.
- 5개 오버레이 전체 픽셀의 alpha 검사 PASS: 정의된 모든 영상 창 안0/밖255. 좌표/크기: placements.json.
- Noto Sans KR 가변 폰트, 최신 굵기 기준 사용. 보조보다 주제/질문을 크게 표현.
- 왼쪽 파란 세로 장식선 없음, 하단 출처/AI 표시 없음, 로고/페이지 번호/UI 잔재 없음.
- 실제 사용자 영상은 미제공. 영상의 자세/측정값 검수는 하지 않았고 완성 MP4를 생성하지 않음.
- 예시 문구의 관찰 원칙은 기존 ACL 조사 자료에 기반. 근거 기록: ../../content/acl-return-to-running/research/sources.md. 새 주제에서는 근거/문장 다시 조사.
- rotation_state.json에 현재 T01, 다음 선호 T02로 기록. 주제/영상 적합성을 먼저 확인하고 직전 형식 반복을 피함.
