# 영상 카드 템플릿 5종

모든 카드 1080×1350. 신규 제작 시 루트 DESIGN_SYSTEM.md의 V4 크기·하단 여백 기준을 적용한다. 기존 미리보기와 source의 폰트 수치는 이전 형태 예시이며 그대로 최신 기본값으로 재사용하지 않는다. 제목·영상 창·해설은 코드 편집 가능. 미리보기의 ACL 달리기 문구는 형태 예시이며 새 주제에서는 근거와 문장을 다시 작성한다. 실제 영상은 미제공이고 사용자가 넣는다.

## 교대 사용

1. [rotation_state.json](./rotation_state.json)의 최근 사용과 다음 후보를 읽는다.
2. T01→T02→T03→T04→T05 순환을 우선하며 직전과 다른 형식을 선택한다.
3. 실제 영상 구도/개수/목적과 맞는지 확인한다. 예를 들어 한 개의 가로 영상만 있다면 T03을 억지로 선택하지 않는다. 적합한 후보 중 덜 최근 쓴 것을 고르고 건너뛴 이유를 기록한다.
4. 새 주제의 제목·핵심 질문·해설로 바꾼다. 예시 ACL 문구/수치를 자동 복사하지 않는다.
5. 납품 완료 후 last_used, next_preferred, recent_used, history를 갱신한다. 같은 주제의 수정만으로 사용 이력을 중복 추가하지 않는다.

현재 사용과 다음 후보는 rotation_state.json에서 읽는다. 이 안내문에 현재 상태를 하드코딩하지 않는다.

## 영상 넣기

- previews/: 안내 문구 있는 설계 시안. 그대로 게시하는 최종물이 아니다.
- backgrounds/: 안내 문구 없는 배경 PNG.
- overlays/: 영상 창이 투명한 PNG. 사용자 영상 위에 전체 캔버스 크기로 올린다.
- [placements.json](./placements.json): 각 창의 정확한 크기/좌표.
- source/: 독립 HTML/CSS, 생성/렌더 스크립트.
- qa/: 360px 미리보기, 경계/겹침/정렬 검수 기록.
- assets/: Noto Sans KR 폰트와 OFL 라이선스.

1080×1350 흰 프로젝트에서 사용자 영상을 창 위치에 놓고 해당 overlays/T0N.png를 전체 화면 크기로 위 레이어에 올린다. T03/T05는 여러 클립이 들어간다. 머리/발/지지면이 잘리지 않게 맞춘 뒤 완성 카드를 동영상으로 내보낸다. PNG 단독으로 영상이 재생되지는 않는다.

## 공통 기준과 검수

큰 제목/굵기 850, 본문 500~650, 핵심 질문을 더 크게. 동일 역할의 좌우 제목은 크기/굵기/행간과 첫 줄 top을 맞춘다. 정적인 3열 목록, 왼쪽 파란 세로 장식선, 하단 출처/AI 제작 표시, 로고/페이지 번호/UI 잔재는 없다. 출처와 실제 영상의 임상 검수는 주제별 기록에 보존한다.

이전 템플릿 제작 당시 렌더 검수 기록(새 주제/V4 재검수를 뜻하지 않음): PNG 15개(미리보기/배경/오버레이 각 5), 각 1080×1350. 안전 영역·가로 넘침·콘텐츠 영역 겹침·T03 좌우 제목 top·영상 창의 모든 픽셀 alpha 검수 PASS. 실제 원본/모바일 시각 확인 후 납품한다. template source의 h1 기본 마진을 제거해 제목/리드 문구 겹침을 수정했다.
