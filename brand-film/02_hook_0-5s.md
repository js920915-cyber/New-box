# STEP 2·3 — 첫 5초 HOOK 세분화

내레이션(확정): **"우리는 재활을, 평가부터 시작합니다."**
원칙: 실제 평가 → 객관적 측정 → 재활운동 지도. 실제 촬영 영상이 있는 컷(포스플레이트)은 AI로 다시 만들지 않고 원본을 쓴다.
