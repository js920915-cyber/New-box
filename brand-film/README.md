## 지켜야 할 것 (요약)
- AI가 만든 숫자·그래프·로고·한글을 그대로 쓰지 않는다. 화면 수치·로고·자막은 Premiere에서 실제 자료로 합성.
- 실제 측정 영상(V4 등)은 AI로 다시 만들지 않고 원본을 색보정해서 쓴다.
- 실제 직원·회원의 얼굴이 나오는 AI 장면은 본인 동의 확인 후 공개. AI로 새로 넣은 인물은 실제 회원처럼 표현하지 않는다.
- 장비명은 실제 보유가 확인된 것만 쓴다(ForceDecks·HHD는 사진에서 확인되지 않음 — 01 문서 0절).
