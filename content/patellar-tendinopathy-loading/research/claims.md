# 카드 문장 ↔ 근거 매핑

| 카드 | 문장 | 근거 | 성격 |
|---|---|---|---|
| 02 | 운동량·강도가 갑자기 늘면 감당 능력을 넘어설 수 있다 | S1 | 모델/임상 해석(“수 있다”). 넘으면 반드시 통증·손상이라고 쓰지 않음 |
| 02 | 문제는 운동 자체보다 갑작스러운 증가일 수 있다 | S1 | 해석 |
| 03 | 힘줄은 부하에 적응하는 조직, 감당 가능한 운동부터 단계적으로 | S1, S2, S3 | S2·S3는 부하 운동 효과 RCT. 컵 크기 = 능력(해부학적 크기 아님)을 카드에 명시 |
| 04 | 5개 운동 부하 지수 수치 | S4 초록 | 직접 결과(건강인). 위험도·치료효과 아님을 카드에 명시 |
| 05 | 힘의 크기·증가 속도·지속(누적) 3요소 | S4 지수 구성 | 그래프는 개념 모식도. 속도(velocity)≠loading rate, impulse≠반복 총량은 캡션 |
| 06 | 근력 회복 뒤 빠르고 반복적인 부하(점프·착지)에 적응 | S3 프로토콜 단계 | 해석. “자동으로 회복되지 않는다”는 단계적 프로그램 설계 근거의 임상적 해석 |
| 07 | 한발 스쿼트 통증 ≤3/10 + 단계 최소 1주 | S3 | 연구 예시. 카드에 “연구 예시”·“모든 사람의 기준은 아님” 표기 |
| 07 | 중량·범위·속도·반복량 조금씩 | S3, S4 | 해석 |
