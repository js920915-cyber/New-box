# 스토리보드 v1 — ACL 재건 후, LSI만 보면 놓치는 것

상태: **기획 합의 중 (대표 승인 전, 제작 금지)** · 2026-11-20
방향: 대표 지시 — Aspetar 가이드라인으로 LSI를 말하고 → 엉덩이 우세(hip dominant) 근거 → 그 자세 → 앞허벅지(quad) 우세 운동 3가지 → 강의 홍보 1장.
과정: 윤서진 실장·고덕현 박사 각자 기획 → 상호 검증 → 아래 합의안 (대화방 r-center-office/talk/2026-11-20-acl-lsi-cardnews.md)
대표 결정: 5장 자세는 **싱글 레그 스쿼트**로 (2026-11-20 13:15, 착지 대신). 주 독자는 **트레이너·물리치료사** (2026-11-20 13:20).

## 0. 독자가 전문가라서 바뀌는 것
- 용어는 그대로 쓴다: LSI, quad/hip dominant, 무릎 폄 모멘트, OKC, SLS. 처음 한 번만 짧게 풀이.
- 숫자를 카드 본문에 올린다: Aspetar 단계별 기준(달리기 복귀 LSI >80% / 고강도 피봇 종목 60°/초 100%), OKC 4주·90°→45°.
- 연구 설계(대상·n·성별·시점·이식 종류)는 카드에 한 줄로 붙인다(전문가는 이걸 보고 판단).
- 6장은 "회원에게 처방할 때 고를 수 있는 선택지"로, 조건(시기·통증·이식 종류)을 붙인다.
- 강의 장과 자연스럽게 이어진다(같은 독자).

## 1. 계기
ACL 재건 후 LSI 기준을 넘긴 회원을 "통과"로 보는 현장 관행. 숫자 너머 움직임(무릎이 실제로 일하는지)을 보자는 제안. (대표 확인)

## 2. 한 문장 메시지 (두 비서 합의, 전문가용으로 다듬음)
"LSI를 통과해도, 수술한 무릎은 아직 일을 덜 하고 있을 수 있다 — 움직임에서 확인하자."
(초안: "한 발로 비슷하게 뛰어도, 양쪽 무릎이 한 일은 다를 수 있어요." — 5장이 싱글 레그 스쿼트로 바뀌어 점프에 한정하지 않게 다듬음. 대표 확인)

**캡션에 넣을 것:**
- Aspetar 숫자는 단계별로: 달리기 복귀 = 앞허벅지 근력 LSI >80% / 프로 선수 고강도 방향전환 종목 복귀 = 등속성 60°/초 앞·뒤허벅지 100% 대칭. 대상은 프로 선수.
- 반대쪽 다리도 약해지면 LSI가 높게 나올 수 있다(Wellsandt 2017 JOSPT, 초록만 확인 → 원문 확인 후 사용).
- Kotsifaki 2022: 남성만·한 기관·대조군 나이·활동 수준 차이·3D 동작분석. 같은 선수들의 앞허벅지 근력 LSI 평균 94%(표 1).
- 무릎 펴기: Aspetar Box 3 — 수술 후 4주부터 90°→45° 제한 범위, 앞무릎 통증 보며 조절, 햄스트링 이식은 이른 OKC에 더 취약할 수 있음 → 전문가 독자이므로 6장 본문에 한 줄로 올림.
- Zang 2026: 수술 4개월 싱글 레그 스쿼트에서 무릎을 많이 쓴 사람일수록 6·12개월 근력이 좋았음(53명, 햄스트링 이식, 관련이지 인과 아님).

## 4. 쓰지 않을 것 / 표현 규칙
- "Quad LSI를 줄이려고 엉덩이를 쓴다" ✕ — 의도는 측정 안 됨. "덜 쓰고, 엉덩이 쪽으로 옮겨 가는 모습이 보고됐어요".
- 엉덩이 쓰는 동작 자체가 틀렸다 ✕ (빨간 ✕ 금지, A/B 시범).
- 97%와 69%를 같은 항목처럼 ✕. 69%는 4장(점프 추진)에만, 5장(스쿼트)에 붙이지 않음.
- 자가진단 체크리스트 ✕. "센터에서 측정" ✕ (힘판·3D 장비 없음).
- 강사 표기: **Andreas Bjerregaard = Aspetar 가이드라인(Kotsifaki R 2023) 공동저자** (PubMed 36731908 저자 목록 확인, 2026-11-20). 3장 지침 → 7장 "가이드라인 공동저자가 직접" 연결 가능. 홉 연구(Kotsifaki A 2022) 저자는 아님. 조인혁은 Aspetar ACL 재활팀 출신(공동저자 아님).
- 7장 문구 규칙: 회차 "1차·2차", 쿠폰·묶음 절약 문구 ✕, 녹화 언급 ✕ (2026-10-27 대표 결정).
