# Adobe Express 편집용 PPTX — PFP 2탄

## 들어 있는 파일
| 파일 | 용도 |
|---|---|
| `pfp-runners-part2_express.pptx` | 편집용 8장. 슬라이드 1080×1350px(4:5), PNG와 같은 크기 |
| `fonts/NotoSansKR-W500~W850.ttf` (6개) | 카드에 쓴 굵기별 폰트. **가져오기 전에 먼저 업로드/설치** |
| `fonts/OFL.txt` | 폰트 라이선스(SIL OFL 1.1) |
| `reference/01~08.png` | 원본 완성 이미지. 가져온 결과와 나란히 비교용 |

## 깨지지 않게 가져오는 순서
1. **폰트 먼저**: Adobe Express에서 `내 브랜드(브랜드 키트) → 글꼴 → 글꼴 업로드`로 `fonts/` 안의 6개 TTF를 올립니다.
   - 폰트 업로드는 계정 플랜에 따라 지원되지 않을 수 있어요. 업로드가 안 되면 아래 '폰트가 없을 때'를 보세요.
   - PC의 PowerPoint로 먼저 확인하려면 6개 TTF를 PC에 설치합니다.
2. **PPTX 가져오기**: Express 홈 → `파일에서 시작/가져오기` → PPTX 선택.
3. `reference/` PNG와 장마다 비교합니다. 제목 줄 위치, 파란 강조 단어, 8번 카드의 구간 막대 위치를 보면 빨리 확인돼요.
4. **PDF로 변환해서 가져오지 마세요.** PDF→Express에서는 문단 합치기·줄바꿈 변경이 생겼던 이력이 있습니다.

## 파일을 이렇게 만들었어요 (깨짐 방지)
- **줄마다 따로 된 텍스트 상자**: HTML 원본 좌표에서 줄 단위로 만들었어요. 자동 줄바꿈·자동 크기 조절을 모두 껐기 때문에 다른 폰트로 바뀌어도 줄이 다시 나뉘지 않고, 가운데를 기준으로 좌우로만 늘어나거나 줄어듭니다.
- **굵기마다 다른 폰트 이름**: `Noto Sans KR W850`(제목·큰 수치), `W800`(항목 제목·핵심 문장), `W700`, `W650`, `W600`, `W500`(본문). PPTX는 '굵게' 켜기/끄기만 표현할 수 있어서 이렇게 나눴어요. **굵게(B) 버튼은 켜지 마세요** — 가짜 굵게가 덧칠됩니다.
- **글자 범위**: 한글 11,172자 전체, 영문·숫자·문장부호가 들어 있어 새 문장을 입력해도 됩니다. 한자는 빠져 있어요.
- **도형**: B01 프레임, 표지 그림 배경, 번호 원, 강조 박스, 2탄 예고 박스, 구분선은 편집 가능한 도형입니다(그림자·테마 효과 제거).
- **그림**: 픽토그램(1·2·6·7장)과 **그래프(3·4장)는 투명 PNG**예요. 그래프 안의 축 숫자·선 이름은 이미지라 Express에서 글자로 고칠 수 없어요. 수정이 필요하면 `source/build_cards.py`의 그래프 함수에서 바꿔 다시 만듭니다.
- **7장 영상 창**: 시범 픽토그램 이미지(`07_도식`)를 지우고 그 자리(x108·y328·864×486)에 영상을 넣으면 됩니다. 창 위치는 `../video-template/placement.json`.
- **8장 구간 막대**: 검정·파랑 두 도형과 글자로 되어 있어 색·글자를 편집할 수 있어요(원본의 바깥 둥근 모서리는 도형마다 직각으로 단순화).
- 레이어 이름: `02_headline_01`처럼 `카드번호_역할_순서`.

## 폰트가 없을 때
Express에 폰트가 없으면 다른 폰트로 바뀌어 글자 폭·굵기가 달라집니다. 이때는 텍스트를 모두 선택한 뒤 같은 디자인 계열인 **Source Han Sans Korean(본고딕)** 또는 **Noto Sans KR**로 바꾸세요. 제목은 Heavy/Black, 본문은 Medium에 가깝습니다. 줄바꿈은 꺼져 있어서 문장이 갑자기 다음 줄로 넘어가지는 않아요.

## 검수 상태
| 항목 | 상태 |
|---|---|
| PPTX 구조 (8장, 1080×1350, 텍스트 상자 73개 전부 줄바꿈·자동 크기 꺼짐, 테마 스타일 없음, 압축 무결성) | 확인 |
| 줄 폭: HarfBuzz(OpenType 셰이핑)로 계산한 PPTX 폰트 폭 vs 원본 | 73줄 최대 3.1px 차이 |
| LibreOffice 렌더 vs 원본 PNG: 세로 위치 | 73줄 모두 ±1px 이내 |
| LibreOffice 렌더 가로 | 가운뎃점(·)·마침표·영문 앞뒤에 LibreOffice가 자체 '아시아·라틴 자동 간격'을 넣어 넓게 보임. 파일 속성이 아니라 LibreOffice 동작이에요. 그렇게 넓어진 상태에서도 줄 넘침·겹침은 없었어요 |
| **Adobe Express 실제 가져오기·폰트 적용** | **미확인** — 이 작업 환경에서 Express에 접속할 수 없어요. 위 1~3번 순서로 가져온 뒤 reference PNG와 비교해 주세요 |
| PowerPoint 실물 열기 | 미확인 (LibreOffice로만 렌더 검증) |

완전한 보존을 보장하지는 않습니다. 가져온 결과가 다르면 어느 카드의 어떤 줄인지 알려주세요. 좌표를 조정해 다시 만들게요.

## 다시 만들기
```
node source/extract_layout.cjs      # HTML 좌표·도식 PNG 추출 → adobe-express/build/
python3 source/make_static_fonts.py assets/NotoSansKR-VF.ttf adobe-express/fonts
python3 source/build_pptx.py        # → adobe-express/pfp-runners-part2_express.pptx
```
