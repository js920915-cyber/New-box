## 넣는 법
- **Express(PPTX)**: 슬라이드의 `NN_사진영상자리_…` 도형과 그 안 안내 글자 3줄을 지우고, 같은 위치·크기로 사진/영상을 넣습니다. 자리 도형을 먼저 선택해 위치·크기를 확인하면 편합니다.
- **영상 편집 앱**: 1080×1350 프로젝트 → 영상을 표의 위치에 배치 → 맨 위에 `media-template/NN-overlay.png`(창이 투명)를 전체 크기로 → 동영상으로 내보내기.
- `NN-background.png`는 안내 글자 없는 배경, `NN-preview.png`는 안내 글자가 있는 설계 시안(게시용 아님).

## 템플릿 선택 (rotation_state.json)
06 = T01(큰 가로 영상 + 아래 질문), 09 = T04(가로 영상 + 큰 질문), 10 = T02(세로 영상 + 오른쪽 해설). 07은 사진 시작/멈춤 2컷(T03 비교형을 사진 1:1로 변형). 다음 신규 주제 우선 후보는 T05(연속 3구간, 이번 미사용).

## 검수
- 자동: 자리 좌표 = DOM 위치, 오버레이 자리 안 alpha 0 / 밖 255, 자리 밖 RGB = 배경 — 5장 PASS.
- **미검수: 실제 사진·영상 없음. 촬영본의 무릎 각도(45°·90°), SLDL 자세·정렬은 넣은 뒤 담당 트레이너가 확인 필요.** 각도 문구와 실제 촬영 각도가 다르면 문구가 틀린 카드가 됩니다.
