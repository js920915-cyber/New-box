# 영상 계획 — 05 카드 (T04 가로 영상 + 큰 질문)

선택: rotation_state.json next_preferred=T04, 최근 사용 T01/T02/T03과 겹치지 않음. 정면 착지 1개 가로 영상으로 무릎 정렬 질문 하나를 보는 목적에 맞다.

| 항목 | 값 |
|---|---|
| 창 | x108, y340, 864×486 (16:9). 템플릿 기본 y320에서 제목 2줄 확보를 위해 20px 내림 |
| 장면 | 2부 "점프" 1단계 제자리 수직 점프 또는 스쿼트 → 착지 3~5회 |
| 길이 | 6~10초, 반복 재생 |
| 구도 | 정면, 카메라 높이 무릎~골반, 머리부터 발·지면까지 프레임 안. 양발과 무릎이 잘리지 않게 |
| 비율 | 가로 16:9 (1920×1080 권장) |
| 관찰 질문 | 착지할 때 무릎이 안쪽으로 모이나요? |

## 넣는 법

1080×1350 프로젝트에 영상을 x108/y340/864×486로 배치 → overlay PNG를 전체 크기로 위 레이어에 올림 → 동영상으로 내보내기. PNG 단독으로는 재생되지 않는다.
