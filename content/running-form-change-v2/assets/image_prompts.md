# Codex 이미지 생성 지시 (러닝 자세 바꿨더니 생긴 일 — 밈 형식, v2)

대표 요청: "억지스럽게 만든 것 말고 밈 같은 재밌는 사진". 연출 사진처럼 보이지 않게, 친구가 폰으로 찍은 듯한 자연스러운 스냅(약간 기울어진 구도, 자연광, 과하지 않은 표정 연기). 스튜디오·광고 느낌 금지.
공통: photos_src/ 에 지정 파일명 PNG, 가로 3:2. 실존 인물·연예인 닮음 금지(유명 밈 속 인물 닮게 하지 말 것), 브랜드 로고·글자·숫자·워터마크 금지, 랜드마크 금지, 손가락·발·관절 자연스럽게, 한국인 성인.
같은 인물: 1·2번은 같은 사람(30대 한국인 남성, 짧은 머리, 회색 티셔츠, 검정 반바지, 흰 러닝화). 1번을 먼저 만들고 2번은 1번을 참고 이미지로 써서 같은 얼굴·옷으로 만들 것. 3·4번도 서로 같은 사람(40대 한국인 여성, 하늘색 바람막이)으로 3번을 참고해 4번을 만들 것.

1. m_knee_ok.png — 공원 트랙에서 달리기를 마친 남성이 한쪽 무릎을 가볍게 툭 치며 '오 이제 괜찮네?' 하는 뿌듯하고 만족한 표정. 상반신~무릎까지, 폰으로 찍은 스냅 느낌.
2. m_calf_pain.png — 같은 남성, 같은 장소·옷. 한쪽 다리 종아리 아래쪽(아킬레스건 부근)을 손으로 잡고 '…어?' 하는 당황+살짝 아픈 표정. 과장된 고통 연기 금지, 현실적으로. 상반신~발까지.
3. m_no.png — 집 거실 소파에 앉은 여성이 스마트폰(화면은 보이지 않게)을 든 손을 몸에서 멀리 밀어내며 고개를 돌리고 '이건 아니지' 하는 표정(거절). 상반신, 정면에서 약간 옆. 밝은 실내.
4. m_yes.png — 같은 여성, 같은 소파·옷. 이번엔 손가락으로 앞쪽을 가리키며 '이거지!' 하는 만족한 미소(승인). 상반신, 3번과 같은 구도·조명.

저장 후 파일명과 해상도만 짧게 답할 것.
