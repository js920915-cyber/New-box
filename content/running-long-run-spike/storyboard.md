# 스토리보드 v3 — 슬기롭게 장거리 마일리지를 쌓는 법

상태: **기획 합의 중 (대표 승인 전, 제작 금지)** · 2026-11-20
방향: 대표 지시(12:50) "슬기롭게 장거리 마일리지를 쌓는 법 — 부상 얘기도 한 번 하면서 어떻게 훈련해 나가면 좋을지". 훈련법이 주인공, 부상 근거는 거리 결정을 설명할 때 한 번.
과정: 윤서진 실장·고덕현 박사 각자 기획 → 상호 검증 → 아래 합의안 (대화방 r-center-office/talk/2026-11-20-long-run-plan.md)

## 1. 계기
하프·풀코스를 준비하며 "이번 주부터 거리를 어떻게 늘리지?" 고민하는 생활 러너. 가을 대회 뒤 봄 대회 준비 시기. (센터에서 실제로 자주 받는 질문인지 대표 확인)

## 2. 표지
- 제목: **슬기롭게 장거리 마일리지를 쌓는 법** (대표 문구)
- 부제(질문형): **다음 롱런은 몇 km로 잡을까?**

## 3. 한 문장 메시지 (대표가 고름)
- **C (두 비서 합의, v3 추천):** "롱런은 조금 늘려 보고, 몸이 어떻게 회복했는지 보고 다음 거리를 정하세요."
- B (실장 v2): "마일리지는 꾸준히, 롱런은 '한 번에' 확 늘리지 않게."

**캡션에 넣을 것 (v3 추가):**
- Run Clever 계획 예시: 4주 블록마다 주간 거리 +23% → 유지 → 유지 → −10% (Ramskov 2016 설계 논문 표 1–3·그림 2). 거리 위주 vs 강도 위주 두 프로그램의 부상 비율은 뚜렷한 차이 없음(Ramskov 2018, 무작위시험, 준비 기간 46~47% 탈락). 16주 거리군 누적 부상 추정 28.0%(표 2) — 천천히 올린 계획에서도 부상은 생긴다.
- Soligard의 "주 10% 미만·ACWR 0.8~1.3"은 호주풋볼·크리켓·럭비리그 근거, 지구력 종목 적용은 합의문도 "연구 확인 전" → 카드에는 원칙(작은 증감·개인별 조절·주관 지표)만.

**남은 이견 — Fokkema 2020 "주간 거리·최장거리와 새 부상 사이 뚜렷한 관련 없음"을 어디에:** 실장 2장 한 줄 / 고박사 캡션. (대표 결정)

## 5. 쓰지 않을 것 / 표현 규칙
- "많이 뛰어도 안전하다", "많이 뛰면 빨라진다"(Fokkema 성능 결과는 타고난 속도 교란 가능) ✕
- "다친 적 있으면 위험 2배" ✕ (오즈비, 신뢰구간이 2 미만 포함) → "더 자주 보고했어요", 수치는 캡션
- 10%는 연구 비교 기준일 뿐 안전선 ✕. "8km 다음은 8.5km" 같은 숫자 예시 ✕ (안전선으로 읽힘, Run Clever는 주간 총거리 단위라 롱런으로 숫자를 옮길 수 없음)
- "회복 주가 부상을 줄인다", "거리와 속도 중 하나만 올리면 덜 다친다" ✕ (Run Clever는 두 프로그램 전체 비교, 유지·감소 주는 두 군 공통)
- "다음 날 괜찮으면 늘려도 된다" ✕ → "조금 더를 고려"
- Nielsen 2014·Damsted 2019는 초록만 확인 → 카드에 쓰지 않음 (Damsted는 21일째만 차이, 56·98일째는 뚜렷한 차이 없음)
- 근력운동 장·부상률 막대그래프는 이번 6장에서 제외 (두 비서 합의, 대표가 원하면 추가)
- "센터에서 측정" 문구 ✕

## 6. 시각
3장: 8km → 12km 비교 그림(+50%). 사진은 대표 실제 러닝 앱 기록 화면(개인정보 가림) 또는 자리 비움.
