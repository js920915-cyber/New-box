# 스토리보드 — 「점프 거리가 같으면 무릎도 회복된 걸까?」 (2026-10-26)

- 대상: 트레이너·재활 관심 독자, ACL 재건술 후 복귀 단계 선수. 핵심 질문: 홉 거리 대칭(LSI)이 좋으면 무릎 기능도 회복된 것인가?
- 답: 아니다. 복귀 승인 선수 26명에서 거리 LSI 97%였지만 도약 시 무릎 일 LSI는 69%. 무릎의 기여가 원래 작아(약 10%) 고관절 몫이 커지면 거리가 유지된다 → Aspetar 2023 가이드라인은 점프의 관절 역학(각도·모멘트·일)까지 보도록 제안.
- 사용자 지시 우선순위: 2~4장 그래프 정확성 → 5장 가이드라인 연결 → 6장 강사 소개. 6장 홍보 문구는 늘리지 않음.
- 색: 파랑=홉 거리·비수술측·강조, 빨강=무릎 일 LSI·수술측 무릎(사용자 지정 — 기본 규칙의 '경고에만 레드'보다 최신 지시 우선), 회색=대조군·고관절/발목.
- 영상: 사용자 지시서에 영상 카드 없음 → 영상 창 없음. rotation_state.json 변경 없음.

## 지시서 대비 바꾼 점
- 03 제목 “같은 점프 거리” → “비슷한 점프 거리”: 실제 LSI 97±4%(완전히 같지 않음). 01 표지 질문은 가정형이라 원문 유지.
- 04·05·06 제목: 84px에서 한 줄 폭(888px) 초과 → 문구는 유지하고 줄바꿈만 변경(05·06은 3줄).
- 04 사진/해부 일러스트 → 누적 막대만: 사용권이 확인된 성인 한 발 홉 측면 사진을 찾지 못했고, 프로젝트 규칙상 직접 그린 일러스트 금지.
- 05 “관절 그래픽” → 글자 중심 박스(고관절·무릎·발목 × 각도·모멘트·일): 그림 대신 사진 원칙. 가이드라인 이름은 하단 footer가 아니라 박스 머리말로 표시.
- 05 문구 “고려하도록” → “회복하도록 제안”: Box 5 원문 ‘normalise’.
- 06 날짜·신청 방법·조인혁 경력: 제공되지 않아 넣지 않음.
